# ADR: しおり生成(FR-034)・安全な印刷(FR-035)・PDF出力(FR-046)の最小実装

- 状態: 採用(Gate P4)
- 前提: Gate P3(合意形成・コメント)適用後
- 関連: DOC-02 FR-034 / FR-035 / FR-046 / FC-087〜089・EX-019、DOC-04 SC-25・SC-26・SC-36、DOC-05 export_jobs、
  DOC-06 `POST /v1/plans/{id}/exports`、DOC-11
- トレーサビリティ: `docs/trace/gate-p4-trace.md`

## 1. 背景

FR-034・FR-046はDB・API・UIのいずれも存在せず、FR-035は公開共有の正規化投影(Gate #34a/#41)だけだった。
しおりは旅行の準備で最もよく使われる出力で、予約番号・住所・電話などの機密情報が紙やPDFで外に出る経路でもある。

## 2. 決定

### 2.1 同じ構造化データから Web・印刷・PDF(FR-034・FR-046)

- backendは「しおり投影」(`app/services/booklet.py`、booklet-v1)だけを作る。HTML・PDFはbackendで作らない。
- frontendは投影を1つの部品(`BookletView`)で描き、Web表示・印刷・PDF保存(ブラウザの「PDFに保存」)を同じ画面で行う。
  印刷用CSS(`booklet.css`)で操作ボタンを印刷せず、A4余白・改ページを整える。
- サーバーでPDFを作らない理由: 日本語フォント・描画エンジン(WeasyPrint等)をコンテナへ追加する必要があり、
  依存とイメージが大きく増える。成果物の保存・期限付きダウンロード(DOC-05 export_artifacts)も不要になる。
  E2Eで同じ画面から `page.pdf()` でPDFが生成できることを確認する。
- テーマ: かわいい・簡潔・家族・学校・出張・アクセシブル・白黒。テーマは見た目だけを変え、載せる情報は変えない。
  白黒でも予定の種類・超過・注意を文字で示す(FC-089)。
- 章: 表紙・目次・日程(移動を含む)・地図(場所の一覧)・予約・持ち物・連絡先・費用・注意事項から選ぶ。並び順は固定。

### 2.2 機密項目はホワイトリストと明示選択(FR-035・FC-088)

- 既定: 予約番号は伏字(末尾4桁)、住所・座標・電話・参加者名は含めない。
- 含められるのは予約番号・住所(座標)・電話・参加者名の4種で、選べるのは旅行の所有者だけ(403 `sensitive_requires_owner`)。
- QR・チケットの中身・PIN・名義・個人の持ち物・個人予算・個人別の負担は、どの設定でも含めない。
  チケットがあれば「QRは含めていない」と注意を出す。
- 機密項目を含む版は、作成者名の透かし(全ページ)と有効期限(90日以内)が必須(DB CHECK でも保証)。
  内容を見られるのは作成者だけ(403 `sensitive_creator_only`)。表示・プレビューは監査に記録する(内容は記録しない)。

### 2.3 版(DOC-05 export_jobs の成果物なし版、migration `d2a7c5e9f4b1`)

- `booklet_exports`: 版番号(プランごとに連番、プラン行のロックで採番)、設定(テーマ・密度・形式・章・含めた項目)、
  生成元の旅程revision、作成時点の投影(Fernetで暗号化)、透かし文言、有効期限、失効。
- 版の内容は作成時点で固定する。旅程が更新されていれば `is_stale` と注意を出す(EX-019)。
  版番号・作成時刻・情報の基準時刻・旅程の版・有効期限を本文の先頭に印字する(SC-26)。
- 失効すると保存していた投影を消去し、以後は410。有効期限切れも410。印刷済みの紙・保存済みのPDFは回収できないことを画面で伝える。

### 2.4 公開ページの検索除外(FR-035)

- 公開共有(`/public/share/{token}/resolve`)の応答に `X-Robots-Tag: noindex, nofollow`・`Referrer-Policy: no-referrer`・
  `Cache-Control: no-store` を付ける。エラー応答にも付ける(404ハンドラがrouteのヘッダーを落としていた不具合も直した)。
  画面側は既に `index.html` の `<meta name="robots" content="noindex,nofollow">` がある。

## 3. 今回の範囲外

- サーバー側でのPDF生成・画像(PNG)出力・期限付きダウンロードURL(DOC-06 export-jobs)。
- 冊子面付(A4両面・中綴じ、FC-090)、表紙の写真・書体の選択、地図画像。
- 閲覧者ごとの透かし(現在は作成者名)、公開版のしおり(公開共有ページは従来の投影のまま)。
