# ADR: 予算・費用(FR-027)・立替・精算(FR-028)の最小実装

- 状態: 採用(Gate P2)
- 前提: Gate P1(持ち物・準備タスク)適用後
- 関連: DOC-02 FR-027 / FR-028 / FC-055・FC-071〜074・EX-013、DOC-05 §8.6・§17・§19、NFR-006、DOC-04 SC-23
- トレーサビリティ: `docs/trace/gate-p2-trace.md`

## 1. 背景

FR-027・FR-028はDB・API・UIのいずれも存在しなかった(travel_plans.budget(Float)と予約・区間のcostだけ)。
立替の精算はグループ旅行の主要な手間であり、金額の扱いを誤ると利用者間の信頼を損なう。

## 2. 決定

### 2.1 金額と通貨(NFR-006)

- 金額は `Numeric(18,2)` とISO 4217通貨コードで保存し、計算は通貨の最小単位の整数で行う(浮動小数点を使わない)。
  APIは金額を文字列で返す(frontendのdecoderは数字の文字列以外を拒否する)。
- 小数3桁の通貨(KWD等)は列の精度で表せないため422で扱わない。小数0桁の通貨はISO 4217に従う(JPY・KRW・VND等)。
- プランの基準通貨は `plan_finance_settings`(無ければJPY)。支出・予算・精算が1件でもあれば変更できない(409)。

### 2.2 換算(FC-072、EX-013)

- 為替のproviderは未接続のため、利用者が支出ごとにレート(1 外貨 = rate 基準通貨)と出典・基準日を入力する。
- レートの無い外貨の支出は `base_amount` を持たず(DB CHECK: fx_rate と base_amount は両方あるか両方無い)、
  集計・差額・精算案から除外し、`unconverted_expenses` の件数で示す。画面は「未換算(集計に含まれません)」と表示する。
  現地通貨の金額は正本として保持する。

### 2.3 分担(FC-073)と丸め

- 分担方法: 均等 / 比率 / 金額指定 / 負担なし(支払った人だけ)。分担行(`expense_shares`)は支出通貨と基準通貨の両方の額を持つ。
- 均等・比率で生じる最小単位未満の端数は「切り捨てで失われた量の大きい順、同じなら入力順」に1単位ずつ配り、
  その行の `rounding_adjustment` に記録する(DOC-05 §8.6「丸め差は明示的な調整行で処理」)。
  合計は常に支出額と一致する(金額指定は一致しなければ422)。基準通貨の額も同じ比で配り、合計は base_amount と一致する。

### 2.4 返金・取消料(FC-074)

- 返金は `kind=refund` の支出として元の支出を参照する(DB CHECK)。通貨は元と同じ、合計は元の額以下。
  分担を指定しなければ元の支出の負担割合で分ける。集計・差額では差し引く。返金のある支出は削除できない(409)。
- 取消料は category=`cancellation` の通常の支出として登録する。

### 2.5 予算(FR-027、FC-055)

- 種類: 旅行全体・カテゴリ別・日別・個人。個人の予算は本人だけが見え、金額は `amount_ciphertext`(Fernet)だけに保存する
  (DOC-05 §19 budgets.private_limit = R)。集計の `my_budget` は本人の負担額と比べる。
- 差異は「予算・実績・残り・超過」で返し、画面は超過を色以外(「超過」の文字)でも示す。
- 予約額(参考)は基準通貨の有効な予約の合計。基準通貨以外の予約は件数で示す。

### 2.6 精算(FR-028)

- 差額 = 支払った額 − 負担する額 + 精算で支払った額 − 精算で受け取った額(正=受け取る)。全員の差額の和は0。
- 精算案は大きい債務者から大きい債権者へ順に相殺する(送金回数が少ない)。案から記録でき、記録は取り消せる(論理削除)。
- メンバーから外れた人も、支出に関わっていれば差額に残り、精算を記録できる(EX-018: お金の関係は消さない)。

### 2.7 権限

| 操作 | owner/editor | viewer |
|---|---|---|
| 閲覧(個人の予算は本人のみ) | ○ | ○ |
| 予算(個人以外)・支出・返金・基準通貨 | ○ | × |
| 個人の予算 | 本人 | 本人 |
| 精算の記録 | ○ | 自分が支払う/受け取る時だけ |
| 精算の取消 | ○ | 自分が記録したものだけ |

監査ログには題名・メモ・金額を記録しない。関連する予約・予定・領収書(文書)は外部キーにしない(B-013の個別削除を妨げない)。

## 3. 未対応(次のGate以降)

- 領収書の画像からの金額読取(OCR)、支払手段・カード明細の取込。
- 精算の送金(決済代行はスコープ外: DOC-02 §7)。
