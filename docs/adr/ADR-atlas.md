# ADR: Personal Travel Atlas(FR-052)の最小実装

- 状態: 採用(Gate P15)
- 前提: Gate P14(旅の振り返り)適用後
- 関連: DOC-02 FR-052、DOC-15 CA-010(Personal Travel Atlas)・CA-007(状態の区別)・CA-011(再訪率)、DOC-04 SC-41
- トレーサビリティ: `docs/trace/gate-p15-trace.md`

## 1. 背景

旅行を横断して「どこを訪れたか」を見る機能が無かった。P12(位置付きの記録)・P13(位置の軌跡)・P14(行った実績)で材料が揃った。

## 2. 決定

- **migrationなし**。Atlasは既存のデータから毎回集計する(区画の表を持たない)。除く旅行の設定だけを
  `users.preferences["atlas"]["excluded_plan_ids"]` に保存する。
- 集計の範囲: 本人が所有するか、承諾済みの共同編集者として参加している旅行(論理削除済みを除く)。
- 材料と状態(atlas-v1。強い順に区画の状態を決める):
  - STAYED: 行った実績で、到着から出発まで30分以上
  - VISITED: 行った実績(時刻なし・30分未満)、本人の位置付きの記録
  - PASS_THROUGH: 本人の位置の軌跡(暗号化してサーバーへ保存した点)だけ
  - PLANNED: 期間が終わっていない旅行の、実績の無い位置付きの予定
  旅行の実績は旅行の共有データとして参加者全員のAtlasに入る。記録・軌跡は本人の分だけを使う(他の人の分は使わない)。
- 区画: region=0.1度(約11km)、area=1度(約110km)。南西の角の座標で表し、北が上の略図(SVG)と、地図の代わりの一覧
  (状態・区画の範囲・旅行・最初と最後の日)を必ず併記する。状態は色だけでなく記号と文字でも示す。
- 指標: 区画の件数(状態別)、再訪率(訪れた区画のうち2つ以上の旅行で訪れた区画の割合。分母0はnull)。順位は作らない。
- Atlasは本人だけが見る(共有・公開は作らない)。年で絞り込める。旅行単位でAtlasから除ける。

## 3. 未実装(本Gateの範囲外)

- 国・都道府県・市区町村の名前(座標→地名の逆ジオコーディングの提供元が未接続のため。地名を推測で作らない)
- 世界遺産・駅・空港などのテーマ、季節・目的・同行者での集計
- 地点単位の公開範囲、Atlasの共有・公開、地図タイル上の表示
- 区画の事前集計(TravelAtlasCell の表)。データが大きくなった時に検討する
