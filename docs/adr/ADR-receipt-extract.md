# ADR: レシートの読み取り(Gate Receipt / FR-027)

- 状態: 採用(2026-11-05)

## 決定

1. **読み取りは候補だけ。** `POST /plans/{id}/expenses/extract-receipt` は値を返すだけで何も保存しない。登録は支出のフォームで確かめた後の `POST /expenses`。
2. **まずサーバーの OCR(tesseract・jpn+eng)と規則で読む。** 外部へ送らず、費用なし。合計は見出しの強さで選び、小計・お預かり・お釣り・税は合計にしない。
3. **AI は同意した時だけ、足りない時だけ。** 合計・日付の確かさが低いか店名が無い時に画像を送る(撮影情報を消し、長い辺 1600px)。FR-059 の `ai.generate` の枠で数える。確かさ 0.8 以上の規則の値は AI で変えない。
4. **画像と読み取った文字は保存せず、ログにも残さない。** 監査は読めた項目の名前だけ。カード番号・電話・氏名は項目にしない。画像の中の指示には従わず、AI の値は形を確かめる。
5. **権限は支出の登録と同じ。** editor 以上、費用を隠された参加者は 403。利用者ごとに 10 分 30 回まで。

## 未確認・制限

- 試験の画像は自作(実際の文字を傾け・ぼかし・影・ノイズを加えた)。実物のレシートでの精度は未評価。OCR は日付の数字を読み違えることがあるので、確認の画面を省かない。
- 実の OpenAI での読み取りは未確認(試験は模擬)。1 回の実費も未照合。
- 画像を領収書として残す機能はない(既存の文書の添付は別の操作)。複数枚をまとめて読まない。HEIC は読めない。
