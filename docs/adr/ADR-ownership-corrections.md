# ADR: 所有者の移譲と、出典・確認・履歴つきの訂正(FR-021・FR-039)

- 状態: 採用(Gate G8)
- 前提: Gate G7 適用後(migration `f4d8a2c6e9b1`)
- 関連: DOC-02 FR-021・FR-039、DOC-04 SC-18・SC-29、DOC-11 §3(共有権限・削除は最近の認証)・§15(Correction)
- トレーサビリティ: `docs/trace/gate-g8-trace.md`

## 1. 背景

旅行の所有者は1人で、共有・削除・参加者の管理ができるのは所有者だけだった。所有者が旅行に行けなくなった・アカウントを
消したい時に、旅行ごと引き継ぐ手段が無かった。また本人の情報を直す時に、何を根拠に・いつ・何から何へ直したかが残らず、
共同の旅行の中の本人に関わる情報(予約の名義など)を所有者へ直してもらう手段も無かった。

## 2. 決定

### 2.1 所有者の移譲(`plan_ownership_transfers`、`app/api/v1/ownership.py`)

- 所有者がパスワードで本人確認して、**参加済みの会員の共同編集者**へ申し出る(招待中・ゲスト・部外者は選べない)。
  相手が**パスワードで本人確認して受け入れた時**に所有者が替わる。断る・取り下げる・期限切れ(既定7日、
  `OWNERSHIP_TRANSFER_DAYS`)で終わる。
- 旅行ごとに手続き中は1件(部分の一意の索引)。手続き中は旅行の削除・受け取る人を外すことを 409
  (`ownership_transfer_pending`)で止める。
- 受け入れの時に行を固定して確かめ直す(所有者がまだ申し出た人か・受け取る人がまだ参加しているか)。崩れていれば 409
  (`transfer_invalidated`)で申し出を無効にする。
- 前の所有者は選んだ役割(編集者・閲覧者)で残るか外れる。受け取る人の共同編集者の行は消す(所有者として二重に持たない)。
- 旅行の中身は旅行ごとのデータ鍵で暗号化しているため、所有者が替わっても掛け直しは要らない。
- アカウントを削除すると、その人に関わる手続き中の移譲は取り下げにする。旅行の書き出しに含める。
- 監査には ID・役割・結果だけ(メールアドレス・旅行名・メッセージは残さない)。両者へ通知する。

### 2.2 本人の情報の訂正(`data_corrections` kind=self、`app/api/v1/corrections.py`)

- 表示名・メールアドレスを、**出典**(本人の申告・公的な書類・予約の確認書・その他)と補足を必ず添えて直す。
  前後の値・補足は**本人のデータ鍵**で暗号化して残し、本人だけが見られる。
- 表示名はログイン中の本人で、メールアドレスはパスワードで本人確認する(確認済みの印を外し、他の端末のセッションを失効。
  PUT `/auth/me` と同じ)。確認の方法(`verification`)も履歴に残す。
- 取り消しは「今の値が訂正の後の値のまま」の時だけ(後から別に変えた値を壊さない)。
- アカウントの書き出しに入り、アカウントの削除で消える。

### 2.3 旅行の中の情報の訂正の申し出(`data_corrections` kind=request)

- 参加者が所有者へ「どの情報を・今の表示・正しい内容・出典」を申し出る。内容は**旅行のデータ鍵**で暗号化する。
- 所有者は全ての申し出、参加者は自分の申し出だけを見る。所有者は旅行の画面で直してから「対応した」、直さない時は
  「見送る」を理由つきで記録する(申し出た人へ通知)。TravelCanvas が自動で旅行の値を書き換えることはしない
  (どの値を直すかは所有者が判断する)。

## 3. 採らなかった案

| 案 | 理由 |
|---|---|
| 所有者が一方的に移す | 受け取る人が知らないうちに削除・費用・共有の責任を負う。同意(受け入れ)を必須にした |
| 移譲で暗号を掛け直す | 旅行のデータ鍵は利用者でなく旅行に属するため不要。鍵の掛け直しは時間がかかり失敗の範囲が広い |
| 訂正の申し出を自動で旅行へ当てる | どの項目(予約の名義・参加者の名前など)を直すかの解釈が要り、誤りを広げる。所有者の判断を残す |
| 訂正の履歴を監査ログに置く | 監査ログには個人の値を残さない決まり(DOC-11)。本人の鍵で暗号化した別の表にした |

## 4. 未実装・制約

- 組織(B2B)の旅行の所有者の移譲は組織の管理の画面で扱う(本 ADR は個人の旅行)。
- 書類の写しの添付による出典の証明は扱わない(出典の種類と補足の文字だけ)。
