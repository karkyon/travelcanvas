# ADR: サポート閲覧と運用の要約(Gate G2 FR-040)

- 状態: 採用(2026-10-21)
- 関連: DOC-02 FR-040・FC-096、DOC-11「運用管理者は利用者の秘密値を原則閲覧不可」、Runbook §8.7、
  `backend/app/services/support_access.py`・`app/api/v1/admin_support.py`・`app/api/v1/privacy.py`

## 決定

1. **なりすまし(impersonation)はしない。** 管理者が利用者として操作する仕組みは作らず、本人が作った「閲覧の許可」の範囲で
   読み取り専用の投影だけを返す。
2. 許可(`support_grants`)は本人だけが作る: パスワードで本人確認(ゲストは不要)・目的(200字まで)・期限(1〜72時間、既定24)・
   範囲(自分が所有する旅行1つ、またはアカウントの概要と旅行の一覧)・問い合わせ番号(任意)。有効は5件まで。いつでも取り消せる。
3. 投影に含めない: 住所・メモの本文・座標・予約番号・PIN・予約者名・連絡先・文書の中身とファイル名・費用・位置の軌跡・
   秘匿制約・記録。含めるのは有無(「メモあり」等)と構造(日程・予定の題名・時刻・予約の種類と施設名・文書の分類ごとの件数)。
4. 閲覧のたびに: 監査(`support_grant_accessed`。許可・本人の ID だけ。目的の本文は残さない)、本人への知らせ、回数・最後の閲覧。
   管理者が自分の許可を見る(管理者の画面を抜け道にする)のは 403。取り消し・期限切れ・存在しないは 404(区別しない)。
5. 運用の要約(`GET /admin/operations`): 有効な共有リンク・Webhook の状態別の件数・DB と文書の容量・削除待ち・有効な許可。
   利用者の個人の値は含めない。不正が疑われる共有リンクは理由つきで止められる(所有者に知らせる)。
