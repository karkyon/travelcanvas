# ADR: 自動取得の精度 — 旅行の目的地を手がかりにする・住所の作り方を正す(Gate PlaceTripArea)

- 日付: 2026-11-09
- 状態: 採用(PR のレビュー待ち。omega-dev の UAT は未実施)
- 起点: 利用者の評価「自動取得・住所取得がまだ使えない。見当違い・住所が正確でない」(2026-11-08)と、引き継ぎ資料 4 章の改善案 A・C・D

## 本物の返事で確かめた原因(2026-11-09、作業場所から鍵の要らない提供元へ実際に送った)

代表 20 件(伊勢・鳥羽・志摩・金沢・京都)を、鍵なし(OpenStreetMap・国土地理院・Wikidata)で引いた。

| 原因 | 実際の例 |
|---|---|
| 住所に道路の名前・別の町の名前を混ぜていた(Nominatim の表示名を全部つないでいた) | 「三重県伊勢市宇治中之切町宇治浦田一丁目館町通線」「三重県鳥羽市坂手町鳥羽三丁目国道42号」 |
| OpenStreetMap の郵便番号は近くの値の推定で、違う番号が多い | 二見興玉神社(本当は 519-0609)に 516-0037 |
| 番地らしい数字だけが市の後ろに付く | 「三重県鳥羽市6」「三重県志摩市4」 |
| OSM の町の区域が実際の住所の町と違う | 伊勢神宮 外宮(本当は 豊川町)が「本町」 |
| 旅行の目的地を使っていない | 「夫婦岩」で福井県の夫婦岩が 1 位 |
| 駅は OSM では「鳥羽」で、名前の一部だけ合う候補として外していた | 「鳥羽駅」が 0 件 |

## 決めたこと

1. **住所は項目ごとの値(Nominatim の address)から作る**: 都道府県・市区町村(郡・区を含む)・町名(quarter。丁目は町名で始まる時だけ)・番地(町名がある時だけ、数字と - だけの物)。
   道路・施設の名前・郵便番号は入れない。項目ごとの値に町名が無い時は、表示名の中の 1 つだけ残る地名を使う。
2. **OpenStreetMap の郵便番号は付けない**。Yahoo!・楽天・Wikidata の郵便番号は今まで通り使う。
3. **町名は国土地理院の逆ジオコーダ(位置 → 町名、鍵不要)で正す**: OSM 由来の住所と、市までの住所に使う。番地は元の町名が同じ時だけ残す。
   逆ジオコーダは最初の応答に 2〜3 秒かかり、応答しない時もある(2026-11-09 に 20 秒以上応答なしの時間があった)。
   1 回は 5 秒で打ち切り、失敗したら 2 分は呼ばない(町名は OSM のまま。結果は悪くならない)。
4. **Wikidata の住所(P6375)に県・市が無い時は、今の住所の県・市を付ける**。県の違う住所は使わない。
5. **旅行の目的地を手がかりにする(改善案 A)**: `POST /spots/place-info`・`POST /spots/geocode` に任意の `plan_id`。
   見られる旅行(閲覧者以上。他人の旅行は 403/404)の `destination`(無ければ旅行名の先頭の語)を Nominatim で位置と都道府県に変える
   (市町村・駅・地名を先に選ぶ。1 日覚える)。予定に位置も住所の都道府県も無い時だけ使う。
   - Nominatim の「近くを優先する範囲」を目的地の周り(±0.6 度)にする。
   - 目的地の 100km 以内(か同じ都道府県)に候補があれば、遠い候補は出さない。**1 件も無い時は遠い候補も残す**
     (行き道の道の駅など、旅行先の外の予定があるため。例: 鳥羽の旅行の「道の駅 お茶の京都 みなみやましろ村」)。
   - 近くに 1 件も無い時は、目的地の周りだけで 1 回探し直す(bounded=1)。
   - 名前の一部だけ合う候補(「ミキモト真珠島」→「真珠島」)は、目的地の 60km 以内なら出す。
   - Yahoo!・ホットペッパーへは目的地の位置を渡さない(半径で絞られ、旅行先の外の予定が出なくなるため)。
6. **候補を選ぶ手がかり(改善案 C の下地)**: 各候補に `distance_km`(予定の位置か旅行先から)・`name_match`(0〜1)・`address_level`
   (1 市区町村・2 町名・3 番地)、応答に `area`(使った目的地)。画面は「旅行先(鳥羽市)から 6.1km · 住所は町名まで」の 1 行を出す。
7. Nominatim は `countrycodes=jp`・`limit=5`。OSM の駅の名前に「駅」を付ける。

## 規約・費用

- 新しい提供元は無い(OpenStreetMap Nominatim・国土地理院・Wikidata は今まで通り。鍵・請求なし)。
- Nominatim Usage Policy: 1 秒に 1 回(1.1 秒の間)・User-Agent・結果の保存は今まで通り。押した 1 回で送るのは多くて 3 回
  (目的地 1 回〈1 日覚える〉・名前 1 回・目的地の周りで探し直す 1 回)。
- 出典の表示(© OpenStreetMap contributors・国土地理院・Wikidata)は今まで通り `sources` で出す。
- 送るのは旅行の目的地の文字・場所の名前・位置だけ(旅程の他の内容・利用者の情報は送らない)。
