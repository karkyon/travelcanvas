# ADR: 同行者(参加者)向けの項目の規則(Gate G2 FR-045)

- 状態: 採用(2026-10-21)
- 関連: DOC-02 FR-021・FR-045、DOC-15 CA-003、Gate F45(共有リンク向けの規則 `share_policy.py`)、
  `backend/app/services/member_policy.py`(正本)

## 決定

1. 所有者が、役割ごと(編集者・閲覧者)の既定と、参加者1人ずつの上書きで「見せない項目」を決める
   (`travel_plans.member_field_policy`、`plan_collaborators.field_policy`。NULL は何も隠さない = 本Gate以前と同じ)。
2. 項目: 予定のメモ・予定の住所と位置・予約・予約番号と PIN の表示・チケット・文書・費用。予約を隠すとチケット・予約番号も隠れる。
3. どの経路からも出さない(経路ごとの対応):
   - 旅程の詳細・当日・予定の作成/変更/移動/並べ替えの応答: 値を null(`hidden_fields` で画面に知らせる)
   - 予約・チケット・文書・費用・取込: 全ての API が 403 `member_field_hidden`
   - 検索: その種類を結果にも件数にも出さず、照合にも使わない(予約番号の末尾の検索もしない)
   - ICS・CSV: 住所を入れない。GPX・KML・経路の試算・最適化・訪問の判定・カレンダーの取込: 位置を隠した人は 403
   - しおり: その章を作れない。他の人が作った版を見る時は章を取り除く
   - 旧形式の旅行(`/travel-plans`): 予算・旧 itinerary を返さない。準備状況・実行可能性の検証・コメント・再計画の費用の影響・
     同期の競合・場所の詳細・次の旅行へ戻す複写からも除く
4. 書き込み: 隠した項目に値を入れて変えようとしたら 403(見えない値を上書きさせない)。画面が空のまま送り返した値は
   「変えない」として扱う(所有者の値を消さない)。
5. 所有者には何も隠さない。設定は監査に残す(項目の名前だけ)。
