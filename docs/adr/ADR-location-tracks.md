# ADR: 任意の位置軌跡(FR-038)の最小実装

- 状態: 採用(Gate P13)
- 前提: Gate P12(写真・メモ・旅行記)適用後
- 関連: DOC-02 FR-038、DOC-15 CA-013(Local-first Location Mode)・CA-014(適応型GPS記録)、DOC-14 §4.4 TRACK MAP、
  DOC-04 SC-43(Privacy & Location)、DOC-11(位置は最小化・暗号化・目的制限・削除伝播)、P9 同意台帳(location)
- トレーサビリティ: `docs/trace/gate-p13-trace.md`

## 1. 背景

FR-038(旅行期間限定、精度選択、即停止、後削除。参加者への位置共有と本人の旅行記記録を分離)は全く無かった。
P9 で作った同意台帳の「位置情報の利用」は、処理する機能が無いため「使っていない(in_use=False)」と表示していた。

## 2. 決定

### 2.1 データ(migration `c1e7a9b3d5f2`、2テーブル新設のみ)

- `location_tracks`: 旅行・本人・保存先(mode)・精度(precision)・状態(recording/paused/stopped)・止まった理由
  (user/trip_ended/consent_withdrawn)・開始・自動停止(旅行の期間の終わり)・停止・点の件数・revision。
- `location_point_batches`: 端末が送った点のまとまり。座標は JSON にまとめて Fernet で暗号化した列だけを持ち、
  平文の座標列は持たない。端末が付けた batch_id は軌跡ごとに一意(再送で二重に保存しない)。
- plan_id は ON DELETE CASCADE(B-012)、点のまとまりは軌跡の削除で連鎖して消える。

### 2.2 記録の方針(CA-013/014)

- 既定はOFF。利用者が旅行ごとに明示的に開始する。開始・再開・点の送信には「位置情報の利用」への同意(P9)が必要。
  同意を撤回すると、その時点で記録中・一時停止中の軌跡を止める(理由 consent_withdrawn)。
- 旅行の期間に限る: 日程(日ごとのIANAタイムゾーン)の最初の日の0時〜最後の日の24時。開始は前日から可能。
  期間の終わり(auto_stop_at)を過ぎた軌跡は、読み出し・送信の時点で止める(理由 trip_ended)。期間外の時刻の点は保存しない。
- 保存先: 「この端末だけ」(既定)は座標をサーバーへ送らない(サーバーは軌跡の開始・停止の記録だけを持ち、点の送信は409)。
  「暗号化してサーバーへ」は点を暗号化して保存する。
- 精度: 高精度=小数5桁(約1m)/標準=4桁(約11m)/省電力=3桁(約110m)にサーバーで丸めて保存する。
  端末側は精度ごとに位置の取得設定(高精度GPSの使用・キャッシュの許容)と間引き(前の点からの距離か経過時間)を変える。
  精度(accuracy)が2kmより悪い点は保存しない。
- 記録はこの画面を開いている間だけ行う(Webブラウザはバックグラウンドで位置を取得できないため)。記録中は画面の上部に
  常に表示し、一時停止・停止をすぐ押せる。

### 2.3 本人だけの記録(参加者への位置共有との分離)

- 軌跡の一覧・詳細・送信・削除は記録した本人だけ。旅行の所有者を含む他の人には、件数も含めて返さない(404)。
- 旅行の閲覧者(viewer)も自分の軌跡は記録できる(旅程は変えないため)。
- 参加者への位置共有(現在地の共有)は本Gateでは作らない(§4)。

### 2.4 削除・書き出し・監査

- 任意の時間帯の点の削除(`DELETE .../points?start&end`): 該当するまとまりを復号して除き、暗号化し直す。
  空になったまとまりも行は残し、同じ batch_id の再送で消した点が戻らないようにする。
- 軌跡の削除: 点ごと消す。画面は端末に残る座標(端末だけの点・未送信の点)も消す。
- アカウント削除(P9): 本人の軌跡は、所有する旅行の分も含めてすぐ消す(本人だけの記録のため、旅行の猶予期間を待たない)。
- 書き出し(P6): 旅行・アカウントの書き出しに、本人の軌跡だけを点を復号して含める。他の人の軌跡は所有者にも出さない。
- 監査には保存先・精度・件数・操作だけを記録し、座標を残さない。エラーにも座標を載せない。

## 3. 代替案

- 点を1行ずつ保存する: 座標の列を暗号化しても行数・時刻から移動の様子が分かり、削除・書き出しも重くなるため、
  まとまり単位で暗号化した。範囲検索はまとまりの最初と最後の時刻で行う。
- 端末だけのモードでも点の件数をサーバーへ送る: 件数も行動の情報のため送らない(DBのCHECKで device_only は0件)。

## 4. 未実装(本Gateの範囲外)

- 参加者への現在地の共有(期限・相手・精度を選ぶ共有)
- バックグラウンドでの記録(ネイティブアプリ・PWAの位置取得)、電池残量・速度に応じた取得頻度の変更、欠測率の観測
- 端末だけの点の暗号化(現在はブラウザのlocalStorageに保存。Offline Pack と同じ鍵管理の決定後に暗号化する)
- 予定ルートと実績ルートの比較(TRACK MAP)、訪問判定(FR-049/050)・旅行記(FR-037)への軌跡の利用、地図表示
- 保護区域(自宅周辺などの自動除外、ProtectedZone)、区間のぼかし
