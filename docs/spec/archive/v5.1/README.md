> **保管の版は実装の判断に使わない**(今の正本は `docs/spec/README.md`・`docs/spec/CANONICAL-SOURCES.md`)。

## 1. 保管の場所と、写しを作らない理由

v5.1 の原本は、プロジェクトの資料室にそのまま残す(内容を 1 文字も変えない)。リポジトリへ全文を写すと、写した時の誤り・
書き換えで「原本と違う保管の版」ができてしまうため、写しは作らない。原本は資料室の下のパスで読む。v6.0 の文書は
v5.1 の本文を引き継ぎ、変えた所に「v6.0:」と書いてあるので、差は v6.0 の文書の中で分かる。
