## 4. 解約・期限・復帰の原則案

1. 解約後もログイン、旅行データ閲覧、保存済み予約・QR・緊急情報、出力、削除、プライバシー設定は継続可能とする。
2. 新しい有料API・AI操作のみ契約期限・残quotaに従って停止する。既存旅行の編集や手入力を止めない。
3. 請求失敗は即時削除や旅行ロックに結びつけず、猶予期間・通知・読み取りと出力の可否を先に定義する。
4. 「復帰保証」は保証範囲を具体化する。候補は解約後90日間の既存旅行・設定保持。バックアップ/削除ポリシーとの整合を確認し、法的保存期間と矛盾させない。
5. 1旅行Passは自動更新なし。旅行日程の変更、キャンセル、未使用、誤購入、返金可否を購入前に表示する。
