## 3. 訂正(2026-11-20 夕)

#156 で全体の検索に足した説明「『プランに追加』は次の画面で入れる旅行を選び、**日と時刻を決めて**その旅行の予定にします」は**実際の動きと違っていた**。
次の画面(旅程の「プランに追加」の窓)で選ぶのは旅行だけで、予定は**その旅行の 1 日目に時刻なしで**入る(`PlannerPage.tsx` の `addSpotToExistingOrNewPlan` が日の番号 0 で追加)。
説明を実際の動きに合わせ、窓にも「選んだ旅行の 1 日目に、時刻なしの予定として入ります。日と時刻は、追加した後に旅程で直せます。」を出した(試験: `SearchPage.test.tsx`・`PlannerPage.test.tsx`)。
窓で日を選べるようにするかは、別の改善(未着手)。
