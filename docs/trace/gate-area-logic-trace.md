# Gate AreaLogic — 比べる方面の決め方の見直し・HOME 動画のちらつき(UAT 2026-11-02 18:16 の指摘)

正本: 利用者の UAT(main `5a7a18c` を omega-dev2 に配備した後)。相談文「家族4人…枚方から車で、高速を使って片道3時間くらいまでの
関西近畿圏や比較的近めの東海、北陸圏…候補地は4件ほど出してほしい」(AI で読み取る・gpt-5-nano)。

## 観測した方面の候補 5 件と誤り

| # | 表示 | 何がおかしいか | 原因(コード上) |
|---|---|---|---|
| 1 | 関西近畿圏 · 位置が見つかりません | 地域の名前で行き先ではない。出発地の枚方自身が関西 | AI の areas_mentioned を全て「あなたが挙げた方面」にした。地域の語を区別していない |
| 2 | 東海 · OpenStreetMap(東京湾の付近) | 地域の名前を地名として照会し、東京都品川区の「東海」を拾った(枚方から約 400km) | 同上 + Nominatim の同じ文字の小さな地名。出発地が未確認で送られず距離の判定が働かない |
| 3 | 北陸圏 · 保谷北町緑地保全地域 | 西東京市の緑地。北陸ですらない | Nominatim のあいまいな一致(「北」の字だけ)を採った |
| 4 | 枚方 · 内蔵の地名表 | 出発地そのもの。行き先ではない | 出発地を方面から除いていない |
| 5 | 高速 · OpenStreetMap(東北) | 移動の手段の語。地名ではない | 行き先ではない語を除いていない |
| 全 | 距離・片道の条件が全て「未計算・未照会」 | 出発地が「枚方から車で、高速を使って…」の文の一節 | AI の出発地をそのまま使い、さらに未確認の出発地を比較に送らなかった(監査 A06) |
| 全 | 「候補地は4件ほど出してほしい」に具体的な行き先が無い | 依頼に答えていない | 条件から行き先を選ぶ処理が無い(AI の案は別の欄に未確認で並べるだけ) |

## 対応

| # | 要件 | 状態 | 実装 | 試験 |
|---|---|---|---|---|
| 1 | 書かれた語を「行き先」「地域の範囲」「行き先ではない語」に分ける | IMPLEMENTED | `jp_gazetteer.region_prefectures`・`regions_in_text`・`is_not_place`、`trip_intent.plan_areas`(規則・AI の両方) | `test_gate_area_geo.py` |
| 2 | 出発地を地名だけにする | IMPLEMENTED | `jp_gazetteer.clean_origin`(「から」より前・表の地名)。AI の値にも適用 | 同上 |
| 3 | 行き先が無い・候補を頼まれた時は、条件に合う方面を選ぶ | IMPLEMENTED | 内蔵の候補表 `DESTINATIONS`(約 50 か所・都道府県・特徴・道路の係数)。片道の目安 = 直線距離 × 道路の係数 ÷ 速度(車+高速 75km/h 等)。条件の時間(希望は 1.1 倍)以内・地域の範囲内・過ごし方の一致の多い順・地域ごとに1件・同じ県に偏らない・件数は文の「4件」 | UAT の文で 4 件(全て関西/東海/北陸・片道の目安 3.3 時間以内・4 県) |
| 4 | AI の方面の案を確かめる | IMPLEMENTED | 地域の範囲の外・片道の目安の 1.3 倍を越える案は出さない(表で分かる時) | `test_uat_scenario_ai_reading_is_cleaned`(札幌を出さない) |
| 5 | Nominatim のあいまいな一致を捨てる | IMPLEMENTED | 結果の名前が照会の語を含む(または逆)時だけ | `test_nominatim_rejects_fuzzy_names` |
| 6 | 比較に出発地・片道の時間を使う(未確認でも位置関係だけ) | IMPLEMENTED | 画面は未確認なら「未確認の読み取りのまま」と示す | `Consult.test.tsx`(AreaLogic) |
| 7 | 画面: 範囲の条件・条件から選んだ方面・理由(直線距離からの目安・道路は未照会) | IMPLEMENTED | `SuggestedAreasPanel`・`AreasStep` | 同上 |
| 8 | HOME 動画が 2 本目から高速で切り替わり続ける(ちらつき) | IMPLEMENTED | 切り替えの後片付けで「残り 0 ms」を覚えていた。切り替えが済んだ時は覚えない | `HeroVideoBackground.test.tsx`(以前のコードでは失敗する) |

**限界(未確認として扱う)**: 所要時間は直線距離からの目安で、道路の提供元の照会ではない(山・半島は係数で補正するが誤差がある)。
候補表は主な観光地だけ。実環境の UAT は未実施。
