## 直す前に測った値(サンドボックス・実際のブラウザ)

利用枠の応答を止めた読み込み中と、返した後の、予定の一覧の上端の位置の差(+ は下へ)。応答は試験の中だけで差し替えた。

| 状態 | 1280px | 360px |
|---|---|---|
| 通常(Free・未接続) | 0 | **+32** |
| 残り少ない | +12 | +44 |
| 上限 | +28 | **+76** |
| 月の上限 | +12 | +60 |
| ゲスト | −12 | +4 |
| 読めない | +1 | +17 |

原因: 読み込み中の場所の確保(Gate G11-Layout)は既定の状態の行の並びに合わせただけで、状態ごとの知らせの有無・文の長さ・
画面の幅による折り返しで高さが変わった。

凡例: `IMPLEMENTED` / `PARTIAL` / `NOT STARTED`。試験: FE = `PlanningUsage.test.tsx`、E2E = `frontend/e2e/gate-g11-usage-layout.spec.ts`。
