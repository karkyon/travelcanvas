# 旅の当日「旅帖ライブ」実装メモ(2026-11-13)

旅行当日の画面(`/plans/:id/today`)を、競合30製品の調査とモックアップ(Claude Design・36画面)にもとづいて作り直した記録です。

## 画面の構成(上から)

| 部品 | 内容 | testid |
|---|---|---|
| ライブ帯 | 何日目/全何日、日付、旅帖の押印数、写真数、当日の設定 | `today-live-band` |
| 旅の糸 | 今日の予定を1本の糸で表示。済み・いま・これからを色で区別 | (nav「旅の糸(今日の道のり)」) |
| 出発の合図 | 「HH:MM に出れば、ちょうど」。4段階(ゆっくり>20分 / そろそろ1〜20分 / いま0〜-4分 / 遅れ) | `today-go` |
| 次の場所のチラ見せ | 写真(思い出の写真か Wikipedia の画像+出典)、営業時間・天気・予約・滞在の目安、電話・予約 | `today-teaser` |
| 空模様の時刻の線 | 時刻ごとの降水確率の棒。屋外予定が雨にかかるとプランBへ誘導 | `today-sky` |
| 当日の地図 | Leaflet+OSM。歩いた線/これからの線、寄り道候補のピン、全画面 | (遅延読み込み) |
| 寄り道チャンス | 30分以上の空き時間に、2km以内のカフェ・甘味・屋内などを候補表示し、影響を見てから旅程に足す | `today-detour` |
| 旅帖 | 着いたら印を押す。写真・音声・ひとことを添えられる。取り消し可 | `today-tabicho` / `today-stamp-dialog` / `today-tabicho-book` |
| 同行者 | 到着見込みの共有(24時間で自動消去) | `today-crew` |
| お助け | 緊急・病院・交番・忘れ物などの連絡先 | `today-help` |
| 移動モード | 全画面の「あと何分」表示 | `today-transit` |
| 朝・旅の前・夜・旅の終わり | 時間帯と旅の段階で表示が変わる | `today-before` / `today-recap` |
| お知らせ | 画面内の通知(閉じた内容は記憶) | `today-notices` |

## バックエンド(DB変更なし)

- `GET /api/v1/plans/{id}/today/guide` … 出発目安・移動時間(区間の登録値、なければ直線距離×迂回係数の「概算」)・空き時間・押印状況・翌日/旅の前の情報
- `POST /api/v1/plans/{id}/today/detours` … 寄り道候補(場所探しの仕組みを再利用、2km以内、旅程にある場所は除外、回数制限あり)
- `PUT/DELETE/GET /api/v1/plans/{id}/today/eta` … 到着見込みの共有。Redis に24時間だけ保存
- 押印は既存の「実績」(EventActual の visited)を使うため、移行(マイグレーション)は不要

## 端末への通知(Web Push、2026-11-13 追加)

無料。ブラウザの標準の仕組みで、ブラウザの会社の窓口(Google・Mozilla・Apple・Microsoft)を通して届ける。
中身は端末の鍵で暗号化(RFC 8291、試験で付録 A の値と一致を確認)、送り手の証明は VAPID(RFC 8292)。外部ライブラリは足していない。

| 通知 | いつ | 種類の鍵 |
|---|---|---|
| そろそろ出発 | 出る時刻の15分前から | depart |
| いま出れば間に合います | 出る時刻〜5分後 | depart |
| 雨の兆し | 屋外・一部屋外の予定の2時間前から、その時刻に雨の予報 | rain |
| 今日の旅程 | 最初の出発の1時間前(6時より後) | morning |
| ○○さんが遅れます | 同行者の到着予定の共有が10分以上遅い時(位置は送らない) | crew |

- API: `GET /push/config`・`POST /push/subscriptions`・`POST /push/subscriptions/remove`・`PUT /push/settings`・`POST /push/test`
- 送る処理: `tcops.py jobs today-push`(2分ごと。`schedule install` で crontab に入る)。同行者の遅れは共有した時に送る
- 保存: users.preferences["web_push"](送り先と端末の鍵は ENCRYPTION_KEY で暗号化。DB の変更なし)。1人5台まで
- 送り先はブラウザの窓口の名前だけ(SSRF の対策)。窓口が 404・410 を返した購読は外す
- 送り手の鍵: `VAPID_PRIVATE_KEY`(空なら JWT_SECRET_KEY から導出)。替わったら画面を開いた時に取り直す
- 条件: https で開いた画面だけ(UAT の https 入口 :4443・Tailscale の https は可、`http://192.168.1.11:4173` は不可)。
  iPhone は「ホーム画面に追加」したアプリから(manifest とアイコンを追加済み)
- 画面: 当日の設定 →「端末への通知」(`today-push`)。許可の確認は「この端末に通知を送る」を押した時だけ

## 電車・バスの実際の時刻(2026-11-13 追加)

日本の電車・バスの時刻を無料で正確に返す経路の API は無い(Google の経路 API は日本の公共交通に非対応、
NAVITIME・駅すぱあと等は有料、公共交通オープンデータセンターは一部の会社だけで経路検索は自前)。そこで:

- 「乗換を調べる」: Google マップを乗換モードで開く(前の予定 → 次の予定。キー不要・無料・正確)
- 「調べた時刻を入れる」: 出発(任意)・所要(分)・乗り物を、次の予定へ向かう移動区間に保存(provider=manual)
- guide は区間の所要時間を使い、出所を `manual`(画面は「乗換で調べた時刻」)にする。出発を入れればその時刻が出る時刻
- 区間を作る・変えるのは旅程を変えられる人(editor 以上)だけ
