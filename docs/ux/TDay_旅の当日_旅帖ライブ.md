# 旅の当日「旅帖ライブ」実装メモ(2026-11-13)

旅行当日の画面(`/plans/:id/today`)を、競合30製品の調査とモックアップ(Claude Design・36画面)にもとづいて作り直した記録です。

## 画面の構成(上から)

| 部品 | 内容 | testid |
|---|---|---|
| ライブ帯 | 何日目/全何日、日付、旅帖の押印数、写真数、当日の設定 | `today-live-band` |
| 旅の糸 | 今日の予定を1本の糸で表示。済み・いま・これからを色で区別 | (nav「旅の糸(今日の道のり)」) |
| 出発の合図 | 「HH:MM に出れば、ちょうど」。4段階(ゆっくり>20分 / そろそろ1〜20分 / いま0〜-4分 / 遅れ) | `today-go` |
| 次の場所のチラ見せ | 写真(思い出の写真か Wikipedia の画像+出典)、営業時間・天気・予約・滞在の目安、電話・予約 | `today-teaser` |
| 空模様の時刻の線 | 時刻ごとの降水確率の棒。屋外予定が雨にかかるとプランBへ誘導 | `today-sky` |
| 当日の地図 | Leaflet+OSM。歩いた線/これからの線、寄り道候補のピン、全画面 | (遅延読み込み) |
| 寄り道チャンス | 30分以上の空き時間に、2km以内のカフェ・甘味・屋内などを候補表示し、影響を見てから旅程に足す | `today-detour` |
| 旅帖 | 着いたら印を押す。写真・音声・ひとことを添えられる。取り消し可 | `today-tabicho` / `today-stamp-dialog` / `today-tabicho-book` |
| 同行者 | 到着見込みの共有(24時間で自動消去) | `today-crew` |
| お助け | 緊急・病院・交番・忘れ物などの連絡先 | `today-help` |
| 移動モード | 全画面の「あと何分」表示 | `today-transit` |
| 朝・旅の前・夜・旅の終わり | 時間帯と旅の段階で表示が変わる | `today-before` / `today-recap` |
| お知らせ | 画面内の通知(閉じた内容は記憶) | `today-notices` |

## バックエンド(DB変更なし)

- `GET /api/v1/plans/{id}/today/guide` … 出発目安・移動時間(区間の登録値、なければ直線距離×迂回係数の「概算」)・空き時間・押印状況・翌日/旅の前の情報
- `POST /api/v1/plans/{id}/today/detours` … 寄り道候補(場所探しの仕組みを再利用、2km以内、旅程にある場所は除外、回数制限あり)
- `PUT/DELETE/GET /api/v1/plans/{id}/today/eta` … 到着見込みの共有。Redis に24時間だけ保存
- 押印は既存の「実績」(EventActual の visited)を使うため、移行(マイグレーション)は不要
