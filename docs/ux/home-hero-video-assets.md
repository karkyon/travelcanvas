# HOME の表紙の背景の動画 — 素材の台帳(Gate HomeHeroVideo)

対象: HOME(ダッシュボード)の旅行が無い時の表紙「最初の旅行を始めましょう」の背景の領域だけ(`EmptyHero`・`.tc-home-hero-art`)。
見出し・説明・ボタン・他の HOME の部分・他の画面は変えない。素材の設定は `frontend/src/config/heroVideos.ts`(`HERO_SCENES_COMMITTED` が空なら手元の UAT 用、どちらも無ければ以前の山並みの絵)。

## 1. 受け取りの条件

- **利用権のある版だけ**(購入・ライセンス済み)。**透かし(例: shutterstock)入りのプレビューは使わない**(2026-11-02 の画面の確認用の
  プレビューには透かしがあった。購入前のプレビューはアプリに組み込めない)
- 音声は使わない(音声の track は配信の前に外す)。切り抜き・色の変更は利用者の承認の後だけ
- 素材を想像で作らない・他の画面の画像を流用しない

## 3. 配信の形(受け取った後に決める)

- 目安: 横 1280〜1600px・7〜10 秒・音声なし・H.264/MP4(互換)+ AV1/WebM(小さい)・1 本 1〜2MB 以下。poster は WebP/JPEG 100KB 以下
- 置き場所: (a) CDN・object storage(推奨。版を URL に `v1` のように含め、`Cache-Control: public, max-age=31536000, immutable`)/
  (b) `frontend/public/hero/v1/`(git に大きな動画を入れることになる。容量が小さい時だけ)
- 4 本を一度に読まない(初めは poster と今の場面だけ。次の場面は切り替えの 2.5 秒前から)。タブが隠れた・表紙が画面の外の間は止める。
  動きを減らす設定・データ節約(Save-Data)の時は poster だけ

## 4. 受入(素材を入れた後)

4 場面が 7 秒(±0.3 秒)ごとに順に切り替わる / タブ・表紙が隠れた間は再生と通信が止まる / 動きを減らす設定で静止画 /
1 本が 404・遅い時も次の場面と静止画・ボタンが使える / スマホ・PC で文字とボタンが読める・押せる / 他の HOME の部分に差分が無い /
合計の容量・1 回の表示の転送量を実測して書く
